What is new at the pond

Duck keeps getting less buggy.

Release notes in normal English: what changed, what was fixed, and what server teams can use now.

Open your dashboard
August 23, 2026Cluster foundation

Duck’s infrastructure has a hive now

Discord server IDs are deterministically divided into isolated cluster queues, with a live honeycomb status page and server-ID lookup.

  • Normal, outage, maintenance, and offline states with uptime.
  • Cluster and Discord server IDs shown in the server viewer.
  • Strict backend-only assignment and health state—browser requests cannot choose either.
August 23, 2026Dashboard and fun update

Fewer Discord waits, more reasons to stay

The dashboard now serves cached server lists during Discord slowdowns, refreshes stale data safely, and avoids duplicate permission requests.

  • Added a visible server refresh flow with automatic cooldowns.
  • Added 2-, 3-, 6-, and 12-month Plus loyalty milestones.
  • Added six new Free and Plus fun commands.
August 23, 2026Tickets

Human-check verification tickets

Server teams can now turn any ticket option into a verification challenge. Duck generates a one-time phrase such as Apple Honeycomb 164,743 and asks the member to type it back before opening the ticket.

  • Failed checks remove the member when Discord permissions allow it.
  • Passed checks open the private ticket normally.
  • Each verification type supports its own label and optional follow-up message.
August 23, 2026Emergency hotfix

AI scanning now follows each server's chatbot model

Experimental channel scanning now uses the same allowlisted model selected for that server's chatbot instead of forcing a separate free-router request.

  • Server-specific model selection is preserved for every scan.
  • Provider privacy routing is copied from the selected model.
  • AI flags remain advisory: Duck suggests; moderators decide.
August 23, 2026Reliability

Smoother tickets and quieter maintenance

Ticket closing now handles stale Discord permission entries more safely, and routine cache maintenance no longer floods logs with noise.

  • More reliable ticket cleanup.
  • Clearer operational logs when something actually needs attention.
  • Public pages now explain feature availability more honestly.
August 21, 2026Dashboard and commands

A friendlier control room

Duck's dashboard gained clearer server controls, improved responsive layouts, a searchable fun-command library, and audit entries written for humans instead of scripts.

  • More Free and Plus fun commands.
  • Better Color Dock, builder, account-menu, and mobile layouts.
  • Plain-language audit history with server-isolated settings.
August 21, 2026Community suite

Tickets, roles, colors, and staff tools landed

Duck grew from a moderation assistant into a configurable community toolkit while keeping every publish action permission-checked on the server.

  • Reaction-role panels, multi-option tickets, Color Dock, statistics, and readable logging.
  • New community moderation controls and safer Discord publishing.
  • A broader dashboard for running different kinds of servers.
August 16, 2026Fun and AI review

Duck learned more games—and how to raise a hand

Playful commands gained their own server controls, while experimental AI review was introduced as a suggestion system rather than an automatic judge.

  • Expanded Free and Plus fun commands.
  • Channel-specific AI review with server rules for context.
  • Moderators remain responsible for every consequential action.
August 15, 2026Security foundation

The public boundary got considerably tougher

Duck's website, sessions, guild access, and dashboard refresh paths were hardened so the browser requests work while the server keeps authority.

  • Stricter server-ID validation and cross-account server isolation.
  • Bounded refresh behavior, more reliable account handling, and safer public endpoints.
  • AutoMod honeypot support with repeat-offender escalation.
August 14, 2026Dashboard launch

Server settings moved into a real control room

The early dashboard became a responsive, full-page workspace with module navigation, server branding, AutoMod configuration, account tools, and Plus loyalty.

  • Each Discord server received an isolated configuration profile.
  • Owner Plus was locked to the configured owner account and server.
  • Motion, loading states, and mobile layouts received their first full polish pass.
August 13, 2026Website launch

Duck waddled onto the web

The original lightweight homepage, guide, and privacy policy launched with a direct Discord invite and Wispbyte hosting support.

  • Public feature explanations without a repository link.
  • A plain-English privacy policy and setup guide.
  • Fast static assets with browser caching.
