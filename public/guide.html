You can still configure core Discord behavior with slash commands:

  3. /synccommandsRefresh the server's slash commands if Discord is showing an old command list.

Duck uses server-scoped commands, so changes appear quickly without duplicate global commands.

03

Build an AutoMod ladder

AutoMod runs locally before a message is sent to an AI provider. Enable the module, then choose the protections you actually want:

  • Rate guards — set one server-wide member delay and optional channel overrides. Staff with Manage Messages are exempt.
  • Swear filter — blocks a conservative local list of severe profanity and slurs.
  • Sexual / NSFW filter — checks text and attachment filenames. It is not presented as perfect image classification.
  • Custom blocked words — Plus servers can add up to 100 server-specific words or phrases.
  • Escalation — choose violations per warning, warnings per removal, then kick or softban.
Hierarchy still wins. Duck cannot punish the server owner, members above its highest role, or members Discord marks as unmanageable.
04

Create no-code custom actions

Custom Actions are an if-this-then-that builder—not a JavaScript executor. Each rule can match every message, text a message contains, or text it starts with. Narrow it to a channel or user ID, then choose an allowlisted result.

Welcome response

If a message starts with hello duck, reply with Hi {user}!

Channel reaction

If anyone speaks in #showcase, react with 💚.

Plus moderation

If a member posts a blocked trigger in one channel, warn, timeout, kick, or softban.

Templates

Replies support {user}, {username}, {channel}, and {server}.

Duck runs at most three matching actions per message, rate-limits repeated triggers, and never evaluates uploaded code.

05

Understand Plus loyalty

Open your profile menu inside a server workspace to see the current tier, progress line, next unlock date, current perks, and next milestone.

  • Free — 5 safe custom actions and memory of 6 recent Duck replies.
  • Duck Plus — 25 actions, automated moderation outcomes, premium AI/TTS, and memory of 16 replies.
  • Three paid months — 50 actions, 30-reply AI memory, and server-specific bot branding.
  • Six paid months — unlimited custom actions and memory of 50 recent Duck replies.

Conversation memory is bounded, expires after six hours, and stays isolated by Discord server. Duck’s AI may also call enabled fun tools; the same plan and dashboard toggles are enforced.

Commands and tools

Talk to Duck in its setup channel, mention @Duck, reply to one of its messages, use a slash command, or use the configured prefix.

Natural language

“Duck, timeout @member for 10 minutes for spam.”

Slash command

/slowmode seconds:15

Prefix command

!warn @member repeated spam

Essential science

/quack

Approval modes

  • Ask for approval — the safest starting point; actions wait for confirmation.
  • Approve for me — trusted requests can proceed under the configured policy.
  • Agent mode — more autonomous, while requester permissions and hierarchy remain enforced.
Recommended: begin with Ask for approval, test commands in a private staff channel, and grant only the permissions your moderators need.
