Set up your pond

Invite Duck, choose where it should listen, select an approval policy, and start using its moderation and community tools.

01

Invite Duck

Use the official invite and choose a server you manage. Duck needs only the permissions required by the features you use.

Open Discord invite
Role hierarchy matters. Place Duck below trusted Administrators and above roles it should moderate. Discord prevents Duck from managing members or roles above Duck's highest role.
02

Configure your server

Once Duck appears online, run these commands as a server Administrator:

  1. /setup channel:#duck-chatChoose where Duck listens for chat and natural-language requests.
  2. /capibility mode:Ask for approvalKeep important actions behind confirmation while your staff learns Duck.
  3. /synccommandsRefresh the server's slash commands if Discord is showing an old command list.
  4. /prefix value:! optionalChoose an additional server-specific prefix for message commands.
  5. /entry-setup optionalConfigure private entry channels, rules links, and staff logging.
  6. /setup quarantine-channel:Voice Jail optionalChoose the destination used by voice quarantine actions.

Duck uses server-scoped commands, so changes appear quickly without duplicate global commands.

03

Commands and tools

Talk to Duck in its setup channel, mention @Duck, reply to one of its messages, use a slash command, or use the configured prefix.

Natural language

“Duck, timeout @member for 10 minutes for spam.”

Slash command

/slowmode seconds:15

Prefix command

!warn @member repeated spam

Essential science

/quack

🛡️

Member moderation

/ban /softban /unban /kick /timeout /untimeout /warn

Handle harmful members with reasons, permission checks, hierarchy enforcement, and approvals.
🧹

Messages and channels

/clear /slowmode /lock /unlock /announce /sendrules

Clean messages, control conversation speed, secure channels, and publish server information.
🏷️

Members and roles

/nickname /addrole /removerole /warnings /clearwarnings

Manage identity and roles while respecting the requester's and Duck's role positions.
🔊

Voice moderation

/disconnect /voicemute /voiceunmute /deafen /undeafen /voicequarantine

Moderate voice safely, including temporary quarantine and controlled release.
🎙️

Voice and TTS

/join /tts /leave

Invite Duck into your voice channel and queue short text-to-speech messages.
📋

Server management

/setup /entry-setup /prefix /capibility /tool /bulk /synccommands

Configure Duck, run a normal-language tool request, choose approval behavior, and prepare multiple confirmed actions at once.
🔎

Information

/serverinfo /userinfo /channelinfo /roleinfo /avatar /ping /test

Inspect the server, members, roles, channels, avatars, latency, and Duck's health.
🎲

Community fun

/quote /remind /roll /coinflip /eightball /ship /curse /spinwheel /duckfact /quack

Save quotes, set reminders, make choices, create polls through /tool, and maintain acceptable levels of duck nonsense.

Approval modes

  • Ask for approval — the safest starting point; actions wait for confirmation.
  • Approve for me — trusted requests can proceed under the configured policy.
  • Agent mode — more autonomous, while requester permissions and hierarchy remain enforced.
Recommended: begin with Ask for approval, test commands in a private staff channel, and grant only the permissions your moderators need.
