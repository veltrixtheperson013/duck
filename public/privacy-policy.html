Plain-English privacy

Privacy without the fine-feathered nonsense.

Duck is designed to help Discord communities—not build profiles about their members.

✓ No ads, analytics, or tracking cookies

Last updated: August 13, 2026

1. The short version

Duck does not collect personal data about bot users for advertising, analytics, profiling, or sale. This website uses no analytics or tracking pixels. If you choose Discord login, it uses a strictly necessary, secure session cookie.

2. Data Duck processes

To respond and perform requested Discord features, Duck may temporarily process the message content, Discord identifiers, server context, attachments, and command details needed for that request. When you sign in to the dashboard, Duck temporarily processes your basic Discord profile, server list, permissions, and OAuth token in server memory. The token is never exposed to website scripts, and the session expires automatically. Moderation records, server settings, subscription status, reminders, quotes, and pending approvals may be stored only when a feature requires them. This operational data is not used to build user profiles or sold to anyone.

3. Third-party AI providers

When an AI feature is used, relevant prompt content and limited server context may be sent to a configured third-party AI provider for processing. Those providers operate under their own privacy policies and data-handling practices.

4. Privacy-focused providers

I try to use privacy-focused AI providers that state they do not collect or train on prompt data. However, third-party processing is not perfect, provider policies can change, and I cannot guarantee 100% privacy. Do not send passwords, payment information, government identifiers, medical records, or other highly sensitive information to Duck.

5. Data sharing

Duck does not sell user data. Information is shared only with the services necessary to operate a requested feature—such as Discord, the configured AI provider, or a configured text-to-speech provider—or when legally required.

6. Your choices

You can avoid third-party AI processing by not using Duck's AI features. Server administrators can remove the bot at any time and should configure features in a way that matches their community's privacy expectations.

7. Changes

This policy may be updated as Duck's features or service providers change. The current version will always be available at duck.wispbyte.app/privacy-policy.
