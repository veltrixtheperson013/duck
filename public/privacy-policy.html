Plain-English privacy

Privacy without the fine-feathered nonsense.

Duck is designed to help Discord communities—not build profiles about their members.

✓ No ads, analytics, or tracking cookies

Last updated: August 22, 2026

1. The short version

Duck does not collect personal data about bot users for advertising, analytics, profiling, or sale. This website uses no analytics or tracking pixels. If you choose Discord login, it uses a strictly necessary, secure session cookie.

2. Data Duck processes

To respond and perform requested Discord features, Duck may temporarily process the message content, Discord identifiers, server context, attachments, and command details needed for that request. When you sign in to the dashboard, Duck temporarily processes your basic Discord profile, server list, permissions, and OAuth token in server memory. The token is never exposed to website scripts, and the session expires automatically. Moderation records, per-server AutoMod and custom-action settings, subscription status, reminders, quotes, and pending approvals may be stored only when a feature requires them. Duck also keeps a small, server-isolated memory of its own recent AI replies for up to six hours; the window has a hard size limit based on the server plan. This operational data is not used to build user profiles or sold to anyone.

3. Service providers

Discord provides the bot, message, member, server, and OAuth infrastructure. Hosted AI requests may be processed by OpenRouter and the model provider selected by the server; a self-hosted installation may instead use Ollama locally. Voice features may use ElevenLabs for text-to-speech or Deepgram for speech processing when those integrations are configured. Stripe processes donations and any future paid checkout; Duck does not receive full payment-card details. A feature sends only the information it needs, and each provider applies its own privacy terms.

4. AI review boundaries

When an AI feature is used, relevant prompt content and limited server context may be sent to the configured provider. If an administrator enables experimental AI scanning, messages in selected channels and recent text from the configured rules channel may be sent for advisory classification. The scanner cannot take moderation action by itself. An authorized moderator must choose an action, after which Duck re-fetches the relevant Discord state and checks permissions and role hierarchy again.

5. Retention

Dashboard login sessions expire after 12 hours. Duck's server-isolated AI reply memory expires within six hours. Pending action approvals expire after 30 minutes by default. Short-lived request, message, and resource caches expire automatically and remain size-bounded. Durable server settings, reminders, quotes, subscription records, and moderation or audit records remain until the relevant feature removes them, the server owner requests deletion, or they are no longer reasonably necessary to operate and secure Duck. Backups, when present, may take additional time to cycle out.

6. Data sharing

Duck does not sell user data. Information is shared only with services necessary to operate a requested feature, when directed by an authorized server administrator, or when legally required. Server configuration and operational memory are isolated by Discord server.

7. Your choices and deletion

You can avoid third-party AI processing by not using Duck's AI features. Server administrators can disable individual modules or remove the bot at any time. A server owner may request deletion of durable data by contacting Duck's operator through Discord and providing the server ID plus enough information to verify ownership. Privacy and security reports may be sent through the same Discord contact.

8. Changes

This policy may be updated as Duck's features or service providers change. The current version will always be available at duck.wispbyte.app/privacy-policy.
